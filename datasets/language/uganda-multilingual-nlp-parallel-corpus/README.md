# Uganda Multilingual Parallel NLP Benchmark (SALT)

Machine Learning and research benchmark dataset curated for Uganda.

## Overview
A multi-way parallel evaluation benchmark corpus designed specifically for Machine Learning, Natural Language Processing (NLP), and Neural Machine Translation (NMT) across five major indigenous Ugandan languages (Luganda, Runyankore-Rukiga, Acholi, Ateso, Lugbara) paired symmetrically with English.

## Source
Sunbird AI / Makerere University AI Lab (SALT Benchmark)
