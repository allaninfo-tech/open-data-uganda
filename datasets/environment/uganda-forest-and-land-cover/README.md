# Uganda Forest & Land Cover Indicators

Standardized dataset for Uganda curated by the Open Data Uganda initiative.

## Overview
Historical time series (1990–2023) tracking changes in forest canopy cover (% of land area) and agricultural land utilization in Uganda.

## Source
World Bank Open Data / Food and Agriculture Organization (FAO)
