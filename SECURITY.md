# Security & Data Privacy Policy

The **Open Data Uganda** project takes data integrity, information security, and individual privacy seriously. Because this repository curates public datasets, data privacy and personal confidentiality are of paramount concern.

---

## 1. Data Privacy & PII Safeguards

Under no circumstances should any dataset in this repository include **Personally Identifiable Information (PII)** or sensitive personal data without explicit public record authorization.

Prohibited data includes, but is not limited to:
- Full personal names tied to private or confidential records
- Phone numbers, personal email addresses, or private residential addresses
- Individual medical records, patient diagnoses, or health identifiers
- Financial account details, personal tax records, or biometric data
- National identification numbers (e.g., NIN)

### Reporting PII Breaches
If you discover personal data or unanonymized records in any dataset:
1. **Do not create a public issue.**
2. Email immediately to: `allan.info.comp@gmail.com` with the subject `[PRIVACY ALERT] Potential PII in Open Data Uganda`.
3. Specify the exact file, line number(s), and nature of the data.
4. The maintainers will scrub the data, remove it from git history if necessary, and release an update promptly.

---

## 2. Reporting Security Vulnerabilities

If you discover a security vulnerability in any of our processing scripts, GitHub Actions workflows, or automation pipelines, please report it responsibly:

- Email the details to `allan.info.comp@gmail.com`
- Please include:
  - Description of the issue
  - Steps to reproduce
  - Potential impact
  - Proposed remediation (if available)

We aim to acknowledge reports within 48 hours and provide updates on resolution progress.
